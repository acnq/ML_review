# ML_review
a review of machine learning with d2l+pandas,
use https://courses.d2l.ai/zh-v2/ as guide

01-05 is content from chinese edition, use environment `d2l`:

```
pip install torch==1.12.0
pip install torchvision==0.13.0
pip install d2l==0.17.6
```

06Appendix is content from english edition, use enviroment `d2l2`
```
pip install torch==2.0.0 torchvision==0.15.1
pip install d2l==1.0.3
```

We ommit the recommendation system, since it only support `mxnet` now, 
waiting for the support of `pytorch` in the future, it is not good to use mixed environment.
